# Oak Path Farms Dashboard

Interactive preview of the Oak Path Farms dashboard (sample data only), built by Prope3 Solutions.

A single static page, `index.html`, with no build step and no dependencies. The logo is embedded.

## Deploy on Vercel

Import this repo at vercel.com/new. Set Framework Preset to **Other**, leave the build command and output directory empty, then deploy.

## Edit the data

Farm, livestock, stock, order, expense and staff data are plain lists near the top of the script in `index.html`.
